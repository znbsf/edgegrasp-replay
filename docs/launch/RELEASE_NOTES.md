EdgeGrasp Replay 0.1.0 is an early preview for turning recorded robot experiments
into editable Blender replays.

Includes three real simulation recordings, a browser workspace, manual shot
editing, portable Blender exports, source-bound validation and an optional Astra
shot planner. Python 3.11+ runs the local toolkit; Blender 4.1.1 and 4.5.13 were
tested for scene creation and round-trip validation.

The static demo previews recordings and downloads shot plans. Use the toolkit
ZIP for complete Blender exports. A live Astra API request is still unverified;
manual workflows need no API key. No new physics or hardware control is performed.

This release is not a Product Hunt contest submission. See the validation and
third-party notice documents in the source repository.
