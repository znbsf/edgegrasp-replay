Start the workspace

Download the local toolkit (ZIP) · Source and validation

Requires Python 3.11+. From the extracted project folder, run RUN_REPLAY.cmd on Windows, or:

python -m pip install -e .
edgegrasp-replay serve --web web
# Open http://127.0.0.1:4319

Export a scene

Choose a recording, edit your shots and select Download Blender bundle. Extract the ZIP, then run Blender 4.x:

blender --background --factory-startup --python build_scene.py -- .
# Outputs replay.blend, preview.png and verification.json
# Add --render-video to render the edited film.

The scene is baked and can be opened without enabling Python auto-run. Every output pose is checked after reopening the file. SO-101 samples use simplified public visual meshes; other hierarchies use schematic links. No physics is recomputed.

Supported input

  • Portable edgegrasp-replay/1 JSON: explicit node hierarchy, timestamped local poses, null gaps and recorded events.
  • Converter for existing EdgeGrasp replay.json exports. Raw arbitrary MCAP, URDF and Gazebo worlds are not directly supported in this preview.
  • The included recordings are simulation evidence. Hardware operation has not been tested.
edgegrasp-replay convert original-replay.json portable.json --title "My experiment"
edgegrasp-replay validate portable.json
edgegrasp-replay export portable.json blender-bundle.zip

Optional Astra shot planner

Set OPENAI_API_KEY in the local server environment before starting. Clicking Plan with Astra sends event labels, reasons, duration and your request to OpenAI's Responses API using gpt-6-astra. No pose arrays, source paths or robot models are sent. Requests can incur your API charges. The planner is capped at one request and 3,500 output tokens per click, with no retries.

AI selects recorded intervals, camera presets and playback speeds. Plans are tied to the input hash and checked before export. They do not modify trajectories or determine physical success. Review the proposed shots before using them.

What the samples show

  • Place, release, retreat: a recorded cycle from a declared offset position; the original result is available under Source evidence.
  • Grasp, then release fails: the historical grasp was verified, but typed release failed. That distinction is retained.
  • Stopped before closure: a historical dispatch refusal. The recording is not silently replaced with a successful attempt.

Source timestamps use preceding recorded display samples during editing. This can repeat samples for slow motion; it never creates new measurement precision. Missing poses hide the affected objects and their descendants.
